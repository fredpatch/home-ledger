# P1.6 — Minimal client (plan) · APPROVED 2026-10-08 · phase-1 · after P1.5

**Goal**: the smallest French, mobile-first client that runs the TASKS "P1.6 carry-over" checklist through the UI. Sources: docs/app-flow.md, docs/design-brief.md, docs/decisions.md, `@suivi/shared` contracts.

## Screens → flows

- **Connexion** (F1.1–3): password + `Rester connecté` (→ `longSession`; checked by default under 1024 px, Q7). Messages from codes: `invalid_credentials` → `Mot de passe incorrect.`, `too_many_attempts` → `Trop de tentatives. Réessaie dans quelques minutes.`
- **Session** (F1.4, reduced): `GET /api/auth/session` at start; any 401 → back to Connexion; an open form is not restored after sign-in (Q8 N, TASKS note). `Se déconnecter` in Réglages.
- **Opérations du mois** (Accueil basic + F4 subset): `GET /api/operations?month=` with month picker, operation rows (design brief §7), the five states (§8; Offline and Locked month do not apply).
- **Saisie / édition** (F2, F3; sheet on phone, dialog on desktop): amount (integer, `inputmode=numeric`; custom keypad deferred, Q6, TASKS note), date (today), category chips → class, envelope and budget month on the derived line (R2, R3, computed with shared `budgetMonthFor` + settings). Only the fields the class needs are shown, from a new shared helper over the R2 matrix (no class picker). Project (Projet / linked transfer), loan person (Prêt), open loan (Remboursement). `Plus d'options`: label, note, `budgetMonth` override, and on edit `Mois automatique` (sends `null`, Q9).
- **Edit / delete**: send `expectedUpdatedAt`. 409 → `Cette opération a changé ailleurs.` + `Recharger`. Delete asks `Supprimer cette opération ?`.
- **Errors and warnings**: 422 `issues[]` → message under each field (French map per issue code; never a raw code). `warnings[]` → non-blocking banner `Les budgets du pot ({potBudgets}) dépassent le pot du mois ({pot}).`, values interpolated from the warning payload, never hardcoded. 5xx/network → error banner + `Réessayer`.
- **Réglages** (F7 entry hidden until P1.9): the 4 editable allowlisted fields + `openingDate` read-only; 422 per field.
- **Double submit**: `Enregistrer` disabled while a request is pending (TASKS note; true idempotency stays deferred).

## Technical

- API client: `fetch` with `credentials: "same-origin"`, `X-CSRF-Token` on POST/PATCH/DELETE (token from login / `GET /api/auth/session`), typed with `@suivi/shared`. Approved lockfile changes: `@suivi/shared` (workspace) and `@tanstack/react-query` only.
- Server: new read-only `GET /api/reference` returning active accounts, categories (class, envelope, `rollsOver`), envelopes, active projects and live open loans with remaining amount (Q1). The form cannot work without it.
- Shared: export `operationFieldRules(class)` (required/optional link fields) from `operation-rules.ts`; `validateOperationShape` stays the authority.
- Formatting: `Intl.NumberFormat('fr-FR')`, `−` for expenses, `+` for income; dates parsed as strings, never through `new Date()` (PROJECT §Gotchas). Styling: CSS Modules + design-brief tokens; inline SVG icons; no UI library.
- **Dev approach**: Vite proxy `/api` → `127.0.0.1:3001` keeps one origin (`APP_ORIGIN=http://localhost:5173`); Chrome/Edge on the PC accept the `Secure` `__Host-sid` cookie on `http://localhost`, Safari does not. iPhone checks over `tailscale serve` HTTPS are deferred to P1.10 (Q10).

## Tests

- Unit (`node:test`, pure modules): field rules per class (shared), French message per issue/API code, amount and date formatting, API client mapping 401/403/409/422/5xx → typed result, derived line. No component rendering and no E2E framework (Q3).
- Integration: `GET /api/reference` (session required, only active rows, no `auth_*`, live open loans only).
- Gate 2: Fred runs the P1.6 carry-over checklist through the UI in Chrome/Edge, then the DB inspection query.
